# SaaS or multi-user hosting

doomlearn is not offered as a hosted service, and one instance serves one Learner. There are no accounts, no tenants and no sharing of a Feed between people.

## Why this is out of scope

Each person runs their own instance on their own Mac, with their own agent logins. The network (ZeroTier) is the access control, and the database, the scheduler and the Usage windows all assume one Learner. A hosted or multi-user doomlearn would need accounts, isolation, billing and a server that is not a Mac, which is a different product.

## Revisit if

The project decides to become a hosted product. Remove a section when it is implemented; delete the file when it is empty.
